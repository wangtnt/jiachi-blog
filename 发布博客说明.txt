📁 文件夹结构
--------------------------------------
博客发布/
├── posts/          ← 存放 Markdown 文章
├── images/         ← 存放文章图片
├── 发布博客.bat    ← 一键发布脚本
└── 发布博客说明.txt ← 本说明文件


📝 发布文章步骤
======================================

第一步：在 Notion 写文章
--------------------------------------
1. 打开 Notion 页面：
   https://www.notion.so/Blog-19855ba2f5bf8024aa60ff8d63825b4a

2. 新建页面，写内容

3. 导出为 Markdown：
   - 点击右上角 "···" → "Export"
   - 格式选择 "Markdown"
   - 下载并解压


第二步：放入本地文件夹
--------------------------------------
1. 将 .md 文件放入 "posts" 文件夹
2. 如果有图片，放入 "images" 文件夹
3. 修改文章中的图片路径（如有需要）


第三步：发布
======================================
【方法一：双击运行】
   双击 "发布博客.bat"
   按提示输入文章标题
   等待推送完成

【方法二：命令行】
   cd C:\Users\Administrator\Desktop\博客发布
   git add .
   git commit -m "添加文章: 文章标题"
   git push

⚠️ 注意事项
======================================
1. 首次使用需要登录 GitHub
   - 运行脚本时会提示输入用户名和密码
   - 密码处输入你的 Personal Access Token
     （不是登录密码）

2. 文章格式
   - 支持标准 Markdown 语法
   - 图片路径建议使用相对路径 ./images/xxx.png

3. 发布失败怎么办
   - 检查网络连接
   - 确认 GitHub 账号密码/Token 正确
   - 联系小兰帮忙排查


💡 提示
======================================
- 可以一次放入多篇文章，一起发布
- 文章发布后需要等待 1-2 分钟网站才会更新
- 如果想撤回文章，从 posts 删除文件后重新运行发布脚本
