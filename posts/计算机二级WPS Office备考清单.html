计算机二级 WPS Office 备考清单（高频考点版）

📅 2026年8月28日 Thinking

计算机二级 WPS Office（科目代码 67）考试环境就是 WPS Office 教育考试版，用官方/半官方题库练最对口。下面把整张卷子按"必刷清单"拆开，⭐ 标的是高频必考点，优先刷这几类。

试卷结构

模块分值说明
选择题20 分背为主，不练操作
WPS 文字30 分长文档排版是核心
WPS 表格30 分函数最难，分值高地
WPS 演示20 分相对简单，尽量不丢分

一、选择题（20 分）

背为主，不练操作，刷题平台题库多过几遍即可。

  • 计算机基础：数制转换（二/十/十六进制）、软硬件组成、存储单位
  • 计算机网络：IP 地址、TCP/IP、HTTP/FTP、浏览器与邮件基础
  • 多媒体：音频/图像/视频格式与压缩原理
  • WPS 常识：三组件功能、扩展名（.et / .dps / .wps）、常用快捷键

二、WPS 文字（30 分）

长文档排版是核心，占分高。

  • ⭐ 样式：新建 / 修改 / 套用、导航窗格
  • ⭐ 自动目录生成与更新、题注、脚注 / 尾注、交叉引用
  • ⭐ 页眉页脚页码（首页不同、奇偶页不同、分节符联动）
  • 分节符 / 分页符、分栏、页面设置（纸张 / 页边距 / 装订线）
  • 邮件合并（批量信函 / 标签）
  • 表格（边框底纹、公式）、图片 / SmartArt / 文本框 / 艺术字环绕
  • 查找替换（通配符、格式替换）、水印、封面

三、WPS 表格（30 分）

分值高地，函数最难，优先刷透。

  • ⭐ 基础函数：SUM / AVERAGE / COUNT
  • ⭐ 逻辑与统计：IF、SUMIF / SUMIFS、COUNTIF / COUNTIFS、RANK
  • ⭐ 查找：VLOOKUP、INDEX + MATCH
  • ⭐ 文本与其他：LEFT / RIGHT / MID、TEXT、ROUND、MOD、TODAY / NOW
  • ⭐ 数据透视表、分类汇总、排序、自动 / 高级筛选
  • ⭐ 条件格式、数据有效性（下拉限制）、单元格自定义格式
  • 图表（柱 / 折线 / 饼 / 组合图）、套用表格样式、分列、合并计算

四、WPS 演示（20 分）

相对简单，尽量不丢分。

  • ⭐ 母版（幻灯片 / 讲义 / 备注）、主题、背景、版式
  • ⭐ 自定义动画（进入 / 退出 / 强调 / 路径）、触发器、切换与换片方式
  • 超链接、动作按钮、SmartArt、图表插入
  • 放映设置：自定义放映、排练计时、隐藏幻灯片、音视频

刷题顺序建议

  1. 专项：先刷「文字 + 表格」（共 60 分），演示跟上。
  2. 套题：整套刷，练时间分配（操作题约 100 分钟）。
  3. 错题：平台自动累积的错题，反复刷到一次过。
  4. 模拟考场：临考前全真模拟 2–3 套，卡时间练手速。
  5. 选择题：碎片时间背，性价比不如操作题，别耗太多精力。
