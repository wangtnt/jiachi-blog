计算机首次开机如何跳过Microsoft 帐户登录，快速进入Windows桌面

📅 2025年3月17日 11:49 网络技术

Created at: 2025年3月17日 11:49

Tags: 网络技术

日期: 2025年3月17日

Windows 11 家庭版系统计算机首次开机时，默认必须完成网络连接才能进入到系统。您可参考《华为 Windows 11 系统计算机首次开机如何配置》完成设置，受网络环境影响，若您的计算机无法连接网络，或卡在网络连接界面、无法进入下一步时，可按如下步骤操作，强制跳过网络连接步骤。

**• 跳过网络连接后，请勿将超级管理员账户 Administrator 注册为本地账户，注册本地账号名称请勿使用Administrator。

• 跳过网络连接后，Windows无法正常同步时间，会导致系统日志或时间戳早于当前操作的时间，非产品出厂质量问题。可参考《Windows 计算机如何同步网络时间》**

  • • 跳过网络连接后，请勿将超级管理员账户 Administrator 注册为本地账户，注册本地账号名称请勿使用Administrator。
  • • 跳过网络连接后，Windows无法正常同步时间，会导致系统日志或时间戳早于当前操作的时间，非产品出厂质量问题。可参考《Windows 计算机如何同步网络时间》

操作步骤：

**计算机首次开机后，进入基本设置操作界面，您可以按界面提示，进入到让我们为你连接到网络界面，按“Shift + F10”键，系统自动调出 cmd 命令框。

若计算机已通过有线连接至网络，则不会弹出此界面，此时若您想跳过有线网络连接，请拔掉网线，再按照以下操作进行。在 cmd 命令框，鼠标光标在命令框点击后输入“OOBE\BypassNRO.cmd”（字母不需要区分大小写），按 Enter 键确认，计算机自动重启。重启后，计算机再次进入基本设置界面，按界面提示操作，当再次进入让我们为你连接到网络界面，将出现我没有 Internet 连接（或暂时跳过）选项，点击我没有 Internet 连接（或暂时跳过）。点击继续执行受限设置或许可协议，将进入下一个操作界面，此时，您已跳过网络连接操作，请您按界面提示完成其他配置，进入到 Windows 系统中。**

  • 计算机首次开机后，进入基本设置操作界面，您可以按界面提示，进入到让我们为你连接到网络界面，按“Shift + F10”键，系统自动调出 cmd 命令框。

若计算机已通过有线连接至网络，则不会弹出此界面，此时若您想跳过有线网络连接，请拔掉网线，再按照以下操作进行。

  • 在 cmd 命令框，鼠标光标在命令框点击后输入“OOBE\BypassNRO.cmd”（字母不需要区分大小写），按 Enter 键确认，计算机自动重启。

  • 重启后，计算机再次进入基本设置界面，按界面提示操作，当再次进入让我们为你连接到网络界面，将出现我没有 Internet 连接（或暂时跳过）选项，点击我没有 Internet 连接（或暂时跳过）。

  • 点击继续执行受限设置或许可协议，将进入下一个操作界面，此时，您已跳过网络连接操作，请您按界面提示完成其他配置，进入到 Windows 系统中。
